# ADR-004: 게임 정체성 — 자유 소셜 월드 vs 진행자 주도 라이브쇼

- 상태: 확정
- 날짜: 2026-07
- 분류: [기획]

## 문제(Context)
행사 포맷에 맞는 게임 방향을 결정해야 한다.

## 대안(Options)
- (a) Zep식 자유 탐험 소셜 월드(근접 채팅 중심)
- (b) 진행자 주도 기수 대항 운동회(집계 게임 중심)

## 결정(Decision)
(b) 진행자 주도 라이브쇼 — "팀메이트 온라인 운동회".

## 근거(Rationale)
행사가 진행자 주도 + 오프라인/온라인 하이브리드(빔프로젝터 송출)로 확정되었다. 라이브쇼에선 "다같이 동시에 반응"이 핵심이라 근접 채팅보다 집계형 게임이 적합하다. 이 결정으로 O/X가 핵심으로 복귀했고, 종목 4종(줄다리기·계주·O/X·마니또)을 확정했다. 모든 종목은 물리 판정 없이 집계·위치·타이밍만으로 승부를 내어 100명 안정성을 확보한다.

## 결과(Consequences)
- 종목 4종(줄다리기·계주·O/X·마니또)이 확정된다.
