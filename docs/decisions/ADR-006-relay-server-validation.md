# ADR-006: 계주 판정 위치 — 서버 완전 판정

- 상태: 확정
- 날짜: 2026-07
- 분류: [기획+백엔드]

## 문제(Context)
왼발/오른발 교대 연타의 유효성 검증을 클라/서버 어디에서 할지 결정해야 한다.

## 대안(Options)
- (a) 클라 판정 + 전진량만 전송(가볍지만 조작 가능)
- (b) 서버가 매 탭의 교대까지 완전 검증

## 결정(Decision)
서버 완전 판정을 채택한다.

## 근거(Rationale)
계주는 릴레이라 동시 연타자가 팀당 1명 = 최대 4명뿐이다. 트래픽이 미미해 서버가 모든 탭을 검증해도 부담이 없고, 치팅 방어까지 해결된다. "동시에 몇 명이 트래픽을 만드는가"가 판정 위치를 결정한 사례다. (줄다리기는 50명 동시라 배칭+속도상한, 계주는 4명이라 완전검증 — 같은 연타라도 설계가 다르다.)

## 결과(Consequences)
- 서버 권위 검증으로 조작을 차단한다.
- 정량 지표: (부하 테스트 후 실측 기입 예정)

## 표준 어휘(Translation)
server-authoritative validation; traffic-profile-driven design
