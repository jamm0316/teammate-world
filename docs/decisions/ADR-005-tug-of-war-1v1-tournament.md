# ADR-005: 줄다리기 — 4팀 동시전 → 1:1 토너먼트

- 상태: 확정
- 날짜: 2026-07
- 분류: [기획+백엔드]

## 문제(Context)
4개 기수가 한 화면에서 동시에 줄다리기하는 구도가 성립하지 않는다.

## 대안(Options)
- (a) 4팀 동시전 유지
- (b) 2팀 1:1 맞대결 + 토너먼트(준결승 2 + 결승)

## 결정(Decision)
1:1 랜덤 대진 토너먼트(NBA 플레이오프식 대진표)를 채택한다.

## 근거(Rationale)
기획 관점 — 1:1이 승부 구도가 명확하고, VS 연출·대진표로 라이브쇼 서사를 확보한다. 백엔드 관점 — 동시 연타 인원 100명 → 약 50명으로 절반이 되어 트래픽 부담이 감소한다. 승패는 인원 차 보정을 위해 1인당 평균 연타 수로 판정하며, 분모는 경기 시작 시점에 고정한다(중도 이탈로 분모가 줄어 점수가 튀는 것 방지).

## 결과(Consequences)
- 정량 지표: 연타 트래픽 추정 — 배칭(0.5초 합산) 적용 시 초당 수천 msg → 수백 msg — (부하 테스트 후 실측 기입 예정)

## 표준 어휘(Translation)
policy change with performance benefit; fixed-denominator fairness rule
